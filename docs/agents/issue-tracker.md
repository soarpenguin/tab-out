# Issue Tracker: Local Markdown

Issues live as markdown files under `.scratch/<feature>/` in this repo.

## Creating Issues

- Create a new markdown file in `.scratch/<feature>/<issue-slug>.md`
- Use the standard issue template

## Triage Workflow

- New issues start with "待评估" label
- Move to "待反馈" if waiting on reporter
- Move to "可自动化" when ready for agent
- Move to "需人工" when requires human implementation
- Close with "不处理" when won't be actioned
